# Jogo da Velha (Tic-Tac-Toe) em Java

Um jogo de console clássico desenvolvido em Java para dois jogadores (X e O).

---

## Sobre o Projeto
Este projeto é uma implementação simples do **Jogo da Velha** utilizando matrizes bidimensionais em Java. O código gerencia turnos alternados, valida jogadas em posições ocupadas ou fora do limite e verifica automaticamente as condições de vitória (linhas, colunas e diagonais) ou empate ("velha").
